# Content Style Guide

1. **Never alter the Elu verse text** in `src/data/poem.json` unless fixing a verified transcription typo against printed editions.
2. **Write for a curious student**: Both `si` (modern Sinhala) and `en` (English) explanations should be warm, plain, and clear. Never copy copyrighted commentary word-for-word.
3. **Use the `APPROXIMATE` set honestly**: When a verse relies on complex Sanskrit/Elu double meanings (*slesha*) or obscure idioms, include its verse number in `APPROXIMATE` in `src/data/index.ts`.
4. **Avoid overclaiming**: Never describe the explanations as "scholarly", "authoritative", or "definitive".
